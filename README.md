# MiniOS - Açıklamalı Yeni Yama

MiniOS, Python ile yazılmış, Tkinter tabanlı küçük bir işletim sistemi simülasyonudur. Pardus üzerinde geliştirildi.

### 🚀 Yeni Özellik: Kütüphanesiz QR Oluşturucu
Herkes `qrcode` kütüphanesi kullanır, bu projede QR kod kütüphanesi var ama kurmak yerine
- Kare matrisleri tek tek hesaplanır
- Qr hazırlanır
- Dış bağımlılık yok, sadece Python
- kütüphaneyi kendisi kurar

### Özellikler
- Masaüstü ve pencere sistemi
- Hesap makinesi
- **QR Oluşturucu (kütüphanesiz)**
- Terminal benzeri araçlar
- 10 Yıl pil gibi çalışan hafif yapı
